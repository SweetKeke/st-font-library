# 字体收藏夹 · Font Library

在 SillyTavern 的扩展设置中收藏和切换字体，支持中、日、英、韩例句与多语对照预览。

## 安装

打开 SillyTavern 的「扩展 → 安装扩展」，粘贴下面的仓库地址，安装后刷新页面。

```text
https://github.com/SweetKeke/st-font-library
```

## 使用

- **在线字体**：粘贴字体样式表的 URL 或 CSS 的 @import 语句。可以留空收藏名称。若字体网站限制自动识别，手动填写 CSS 字体名即可。
- **本地字体**：选择 TTF、OTF、WOFF 或 WOFF2 文件，单个文件最大 25 MB。名称可留空，插件会使用内置名称或文件名。
- **字体与字重**：勾选「启用字体覆盖」应用所选字体。默认沿用主题字重，滑块仅调整预览；勾选「将预览字重用于聊天正文」才应用到正文。静态字体的粗档使用描边，轻档使用淡化。
- **收藏管理**：在「已添加字体」中选择、改名或删除。列表最多显示四行，可以滚动查看更多。

## 收藏放在哪里

仅通过仓库链接安装时，收藏列表和偏好保存在当前浏览器的 localStorage，本地字体保存在 IndexedDB。刷新后仍可使用；清除站点数据会清除这些收藏。在线字体需要联网访问原站。

如需在同一酒馆账号下跨浏览器收藏，可由酒馆管理员将本仓库的 `server/st-font-library` 文件夹复制到 **SillyTavern 安装目录**的 `plugins/` 下，确认酒馆已启用服务端插件后重启。配套服务把收藏逐项保存在当前账号数据目录的 `st-font-library/` 中。只有前端扩展时无需此步骤。
