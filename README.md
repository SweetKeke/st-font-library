# 字体收藏夹 · Font Library

在 SillyTavern 里收藏、预览并随时切换字体。支持在线 CSS 字体与本地字体文件，内置中 / 日 / 英 / 韩多语预览。

## 功能

| 能力 | 说明 |
| --- | --- |
| 在线字体 | 粘贴字体样式表地址，或整段 `@import`；自动识别 `font-family` |
| 本地字体 | TTF / OTF / WOFF / WOFF2，单个文件不超过 25 MB |
| 多语预览 | 中文、日本語、English、한국어，可四语对照 |
| 字重调节 | 静态字体用描边模拟加粗、轻档淡化；可变字体直接使用真实字重 |
| 应用范围 | 仅聊天正文，或整个界面（含提示词管理器、预设面板、设置项） |
| 收藏管理 | 选择、改名、删除、分页浏览 |
| 备份迁移 | 导出 / 导入 JSON，本地字体文件一并打包 |

## 安装

1. 打开 SillyTavern 的 **扩展 → 安装扩展**；
2. 粘贴仓库地址，安装完成后刷新页面（Ctrl + F5）：

```text
https://github.com/SweetKeke/st-font-library
```

安装后，在 **扩展设置** 里找到「字体收藏夹 · Font Library」。

## 使用

### 添加字体

- **在线字体**：填入字体样式表的 URL（或包含 `@import` 的代码）。收藏名称可留空；若字体网站限制自动识别，手动填写「CSS 字体名」即可。
- **本地字体**：选择字体文件，名称可留空，插件会读取字体内置名称或文件名。勾选「可变字体」可启用 100–900 全字重。

### 应用与字重

- 勾选 **启用字体覆盖** 后，选中的字体会立即生效；
- 预览滑块只影响预览框；要让字重进入正文或界面，使用 **字重应用范围**：

| 选项 | 效果 |
| --- | --- |
| 仅预览 | 只改预览框，正文沿用主题字重 |
| 聊天正文 | 应用到 `#chat .mes_text` |
| 整个界面（全局） | 应用到插件覆盖的全部界面文字 |

静态字体只有一个字重时，加粗通过描边模拟、较轻的档位会淡化文字；可变字体则直接使用真实字重。 描边在大范围（全局）应用时会增加渲染开销，卡顿时可切回「仅预览」或「聊天正文」。

### 应用范围

**字体应用范围** 决定字体覆盖到哪里：

- **仅聊天正文与角色名**：不改变界面字体；
- **主要酒馆界面和聊天内容**：会一并接管主题的主字体变量（`--mainFontFamily`），因此提示词管理器、预设面板、设置项这些「不继承 `body` 字体」的区域也会跟随。

## 数据与备份

收藏列表与使用偏好保存在当前浏览器的 `localStorage`，本地字体文件保存在 `IndexedDB`。刷新、重启酒馆后仍然可用；**清除站点数据会清除这些收藏**，在线字体还需要能访问原站。

换电脑或清理浏览器数据之前，先点面板里的 **导出收藏**：

- 导出文件是一个 JSON，包含全部条目与当前偏好；
- 在线字体只记录名字与 CSS 地址，体积很小；
- 本地字体会以 Base64 一并打包，文件约为原字体的 1.37 倍；
- 在新环境用 **导入收藏** 恢复，重复条目会自动跳过（不会重复添加）。

## 常见问题

**字体加了但没变化？**
先确认「启用字体覆盖」已勾选，再检查 CSS 字体名是否与样式表里的 `font-family` 完全一致；在线字体需要能访问对应 CDN。

**界面某些区域没跟着变？**
把「字体应用范围」切到「主要酒馆界面和聊天内容」。

**图标变成方框或乱码？**
插件已排除 Font Awesome、Material Icons 等图标字体；如果仍有异常，请附上截图与出问题的元素。

**更新后版本号没变？**
浏览器缓存了旧脚本，Ctrl + F5 强刷一次。
